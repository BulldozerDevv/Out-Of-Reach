# Out of Reach

## About the Game

**Out of Reach** is a 2D puzzle platformer prototype created for the [University of Waterloo Spring 2026 Game Jam](https://itch.io/jam/university-of-waterloo-spring-2026-game-jam), based on the theme **"GET AWAY"**.

The main idea is simple: you're trying to reach the end of a level, but the world itself keeps getting away from you!

Instead of escaping from enemies, you have to deal with parts of the environment that try to avoid you. This turns ordinary platforming mechanics into unusual puzzles that require creative thinking.

**Play the game:** [Out of Reach on itch.io](https://bulldozerdev.itch.io/out-of-reach)

## Current Gameplay

The playable prototype currently demonstrates two main mechanics:

- **Escaping Platforms:** Platforms try to move away when the player approaches them, making it harder to reach certain areas.
- **Gravity Zones:** Gravity gets reversed in specific areas of the map, forcing the player to adapt their movement and find a way through.

## Existing but Unused Mechanics

Some mechanics were implemented in the Godot project but weren't integrated into the playable level:

- **Escaping Keys:** A key that runs away when the player approaches it.
- **Escaping Doors:** A door that tries to move away from the player, making reaching the exit another puzzle.

There is also a **Box** object in the project. It is not part of the current gameplay, but developers can use it as a starting point or inspiration for implementing their own puzzle ideas.

## Ideas for Future Features

I had several additional ideas that I wanted to implement, but unfortunately, I didn't have enough time to finish them.

Here are some possible mechanics that could be added in the future:

- **Escaping Buttons:** Buttons slide away when the player tries to press them, making puzzle activation more challenging.
- **Shy Enemies:** Enemies are afraid of the player and run away instead of chasing them. Their movement could be used to solve puzzles.
- **Escaping Walls:** Certain walls move away when the player looks at them, but return when the player looks elsewhere.
- **Escaping Exit:** The level's exit changes its position whenever the player gets close to it.

These are just suggestions. Feel free to experiment with them, improve existing mechanics, or come up with completely different ideas!

## Project Status

This project is currently a **prototype**, not a complete game.

I didn't have enough time to polish the gameplay, create additional levels, or integrate all the mechanics I had planned. Instead, I focused on creating one playable prototype level to demonstrate the core concept.

## Contributions & Ideas

I'm publishing this project on GitHub so other developers can explore the code, experiment with the existing mechanics, and contribute their own ideas.

Feel free to fork the project, modify it, and build upon it!

**The goal is to see how many things in a game can possibly get away from the player.**
